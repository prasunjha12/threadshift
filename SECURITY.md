# Security reports

ThreadShift is an early preview. Privacy boundaries are described in [docs/privacy.md](docs/privacy.md), and checked scope and limitations in [docs/validation.md](docs/validation.md).

Use GitHub's private vulnerability reporting feature when it is available on this repository. If it is unavailable, open an issue requesting a private contact channel without disclosing exploit details or confidential data. Do not post credentials, real session archives or private workspace contents in public issues.

Include the affected revision, a synthetic reproduction, the expected privacy boundary and the observed result. Native destination tools use their own permissions; ThreadShift does not sandbox their later workspace access.
